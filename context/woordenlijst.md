# Woordenlijst

| Term | Betekenis |
|---|---|
| AC | Acceptatiecriterium: toetsbare regel in de spec, in de vorm Gegeven / Als / Dan |
| Agent | AI die zelfstandig meerdere stappen uitvoert (bestanden lezen, code schrijven) |
| Beslislog | Lijst van besluiten: wat, waarom, wie, en wanneer het weer open gaat |
| CI | Automatische checks bij elke pull request (tests, token-lint) |
| Dimensie | Een van de vier kanten van de quickscan: strategie, cultuur, proces, uitkomst |
| Feature-ID | Vaste code (FEAT-001) die spec, Figma, branch en tests verbindt |
| HMW | "Hoe kunnen we…?": vraag die een probleem omzet in een ontwerpopdracht |
| Niveau | Uitslag van de quickscan, 1 t/m 4 (zie spec §3) |
| PR | Pull request: voorstel voor een wijziging dat eerst wordt gereviewd |
| Token | Vastgelegde ontwerpwaarde met een naam, zoals `color.accent` |
